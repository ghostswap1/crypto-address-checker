How the checker works

Most crypto addresses carry a checksum: a few bytes computed from the rest of the address. The checker decodes the address, recomputes that checksum and compares it. A typo, a missing character or a swapped letter breaks the match, so the address is flagged before you send anything.

  • Bitcoin, Litecoin, Dogecoin, Dash, TRON, XRP, Zcash t-addresses: Base58Check with a double SHA-256 checksum, plus the version byte that says which coin and address type it is.
  • SegWit and Taproot: Bech32 and Bech32m checksums, including the witness version and program length rules.
  • Monero: Monero's block Base58 and a Keccak-256 checksum, plus the network byte (mainnet, stagenet or testnet).
  • Ethereum and EVM chains: the EIP-55 checksum hidden in the mix of capital letters. An all-lowercase address has no checksum, so the checker warns you.

What it can't tell you: a valid address is correctly formed, but that doesn't prove who owns it. It also can't tell whether the service you're sending from supports that network. An EVM address looks the same on Ethereum and BNB Smart Chain, so always pick the right network too.

Frequently asked questions

How do I check if a crypto address is valid?

Paste the address into the checker. It decodes the address and recomputes its built-in checksum (Base58Check for Bitcoin, Bech32 for SegWit, Keccak-256 for Monero, EIP-55 for Ethereum). If one character is wrong, the checksum no longer matches and the address is shown as invalid.

Does a valid address mean my funds will arrive?

No. A valid result means the address is correctly formed for that coin. It does not prove who owns it, and it cannot tell you whether the receiving service supports that network or address type. Always check the network as well as the address.

Is my address sent anywhere?

No. The checker runs entirely in your browser. The page makes no network requests while checking, and the code is open source on GitHub so anyone can confirm it.

Why does my Zcash u1 or zs address show a warning?

Unified (u1) and shielded Sapling (zs) addresses are valid Zcash addresses, but many exchanges and instant swap services, including GhostSwap, pay ZEC only to a transparent address (t1 or t3). Use your wallet's transparent address for the payout, then shield the ZEC after it arrives.

How do I check a Monero address?

Paste it into the checker. A Monero address is 95 characters (106 for an integrated address) and starts with 4 for a standard address or 8 for a subaddress. The checker decodes Monero's Base58 and verifies the Keccak-256 checksum, and it also tells you whether the address is for mainnet, stagenet or testnet.
